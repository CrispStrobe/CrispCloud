# CrispCloud 1.3.5 (44)

PDF viewing now offers PDF Editor, CrispOffice and native PDFx engines with
persistent primary/secondary choices in Settings. F3 defaults to the read-only
PDF Editor surface; Shift+F3 opens the configured alternate. F4 editor choices
and Shift+F4 remain configurable. Zoom, fit, rotation and footer percentages
share the corrected viewport behavior, and large files retain the streaming
native fallback.

The integrated Office source is the reconciled Office source `bbfc015a`, verified against all
3,017 managed files; the independent legacy parser remains at `48957121`.
Recent Downloads, Zotero, VBA, document review and font work is retained.
Standalone CrispOffice additionally includes selectable credential stores,
20 remembered Mail accounts, guarded switching, safe reply/forward actions,
shared Mail chrome and reader palette/repaint fixes. The standalone Mail UI is
not added to CrispCloud's file-browser routes by this release.

Local validation: 105 combined CrispCloud PDF/preferences/routing/editor/font
regressions passed; the refreshed Office source has 876 Mail/Downloads/credential/theme/layout host
tests and 154 controller/layout comparisons passing (eight image-only fixture
cases skipped), with the earlier 85 reader/UI checks also passing, plus the temporary-keychain native suite.
Earlier signed PDF preview acceptance is recorded in
`docs/validation/pdf-choices-20261120/`. Physical Mail scrolling-flicker acceptance
is still pending an unlocked desktop; synthetic scrolling tests are passing.
The newest reconciliation incorporates incremental Word layout, additional
Zotero table/citation handling, Word and PowerPoint VBA, and Mail forward/recovery
fixes. The earlier decision to defer the isolated draft layout head was superseded
by the reconciled branch and its fresh local controller/engine qualification.

The Apple source-evidence refresh preserves the existing outside-France release
route, declarations, reviewed groups and recipients. Since the previous evidence,
the final lockfile changes are clock 1.1.3 and stack_trace 1.12.2
(utility/test dependencies). Dependency-graph collection also reconciled test_api
to the Flutter 3.47.8 SDK requirement, 0.7.12, and removed its unused listen
dependency. Application runtime dependencies are unchanged by this reconciliation. Reviewed source changes concern Office,
PDF/font rendering, Nextcloud PROPFIND/file operations and stable local signing.
No encryption algorithm or provider was replaced; Filen and Internxt remain.
This records source identity and preserves the existing assessment; it makes no
new government classification claim.

The `v1.3.5` tag triggers the existing multi-platform binary workflow. Its release
stays a draft until the required asset inventory is complete. TestFlight delivery
receipts are recorded separately after upload and Apple processing.

The completed first build had matching app/extension versions (1.3.5 / 44); an intermediate product still showed its old version. The release wrapper additionally makes version settings explicit for both native targets, with inherited Xcode settings preserved; 11 distribution checks passed.

Final qualification caught and fixed an incoming incremental-layout cache error: paragraph breaks computed before a frame-wrapped edit could survive that edit and be reused after the paragraph moved away from the frame. Wrapped layout now invalidates that ordinary-break entry. All 18 incremental differential/prefix tests pass, including the three formerly failing seeded sequences; the broad engine and controller reruns are retained in the release evidence. Candidate builds from before this repair are excluded from release.
