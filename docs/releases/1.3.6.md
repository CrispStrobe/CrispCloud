# CrispCloud 1.3.6

This release includes the current integrated CrispOffice source, the Mail and PDF viewer work, and corrections found by the cross-platform release gate.

- Restore localized Office labels, word-count commands, and PDF viewer controls in all supported languages.
- Open detached KeePass attachments safely in read-only mode; workspace registration now waits for the correct Flutter lifecycle phase.
- Integrate CrispOffice main `52c7f27f`, including the latest Word VBA paragraph spacing and unit conversions.
- Repair cold-run Office preview tests and streaming archive verification without skipping their rendering, safety-limit, or integrity assertions.
- Resolve spaCy test dependencies in release CI and retain existing release drafts during reruns.
- Build the JavaScript Web artifact without the discarded WebAssembly diagnostic compilation.

The public release stays a draft until every required platform binary and signing receipt has uploaded. macOS and iOS TestFlight delivery use the separate signed App Store workflows and the existing reviewed tester groups.
