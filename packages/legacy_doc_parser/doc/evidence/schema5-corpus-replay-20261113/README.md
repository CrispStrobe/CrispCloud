# Schema 5 replay of the retained 24-case corpus

This is a new, read-only XML observation of existing evidence. It does not replace the original native results, rerun a converter, or change the measured parser runtime. All **62 initial DOCX packages** were read successfully: 14 original DOCX sources, 24 native DOC-to-DOCX exports, and 24 parser exports. Their bytes and each shared binary DOC were checked against the retained `final-native-c5ff75e7` receipts before observation. The 72 subsequent binary-save cycles are outside this bounded replay.

The parser under measurement remains `c5ff75e76163d9abbdd44a9f2a7c5ad210929289`. The XML reader is the separately identified schema-5 oracle at commit `c73749df59d0978c8bcd20710a2ae92184fab11a`, tree `ead7400c4cb79fe24acecb418ed8a1c41bab661e`. Its exact `oracle.py` and `structure.py` Git objects are retained under `oracle-source/`, with SHA-256 and Git blob identities in `source-identity.json`. They read OOXML; they do not import the Dart parser, run an office application, or establish layout equivalence.

## Findings and attribution

Only `word`, `note-markers`, and `bookmarks` differ in schema-5 `inlineContent` between the native and parser exports of the **same binary DOC**. The other 21 cases have equal inline snapshots; many contain no field, glyph, bookmark, note, or hyperlink events. Equality on an empty feature is not coverage of that feature. Full strict semantic snapshots retain additional formatting and structural differences without labeling them all defects.

### Coverage gaps exposed by the replay

There are **zero `w:sym` glyph events across all 62 packages**. None of the original or native packages contains a field event in this projection. The only parser field event is the internal bookmark HYPERLINK described above. Thus the old 24-case corpus does not establish decoding or round-trip behavior for font-specific symbols, REF/PAGEREF/NOTEREF, TOC/PAGE fields, nested fields, or their malformed boundary controls. Independent field and symbol fixtures added in the current investigation supply distinct evidence; they must not be retroactively attributed to this corpus.

The schema-5 inline reader also records body `footnoteReference`/`endnoteReference` targets, not every note-internal `footnoteRef`/`endnoteRef` marker as an inline event. The original `note-markers` fixture deliberately has missing, mid-paragraph, later-paragraph and repeated internal markers. The native and parser outputs normalize these. Equal body-anchor events cannot settle those internal marker semantics. The original source XML and the complete structural snapshots remain available; this replay makes no new source-byte attribution for that normalization.

No new parser runtime correction is justified by this bounded replay beyond the known link work. The actionable follow-ups are broader independent field/glyph controls and, if table-column bookmark preservation is pursued, inspection of the actual shared binary operands before editing a decoder.
