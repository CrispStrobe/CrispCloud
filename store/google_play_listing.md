## Full description (max 4000 chars)
CrispCloud is a privacy-focused file manager that connects all your cloud storage accounts in one app. Browse, transfer, and sync files across multiple providers without switching between apps.

Supported cloud providers:
• Internxt — end-to-end encrypted storage
• Filen — zero-knowledge encrypted cloud
• pCloud — fast European cloud storage
• SFTP/SSH — connect to any server
• FTP/FTPS — legacy server access
• WebDAV — Nextcloud, ownCloud, and more
• Local storage — SD cards, USB drives via SAF

Key features:
• Dual-panel file browser — drag and drop between any two sources
• Cloud-to-cloud transfers — move files between providers directly
• Delta sync — block-level synchronization for efficient bandwidth use
• End-to-end encryption — optional client-side AES-256-GCM encryption
• File preview — images, PDFs, videos, text, and code with syntax highlighting
• Built-in file editor with syntax highlighting for 20+ languages
• Batch rename with regex patterns
• Duplicate file finder across clouds
• FUSE mounting on desktop (Linux/macOS)
• Biometric authentication (fingerprint / face)
• Home screen widget for quick access
• Background sync with WorkManager
• Share-to integration — upload files from any app
• Dark mode and Material You dynamic colors

CrispCloud runs on Android, iOS, Windows, macOS, Linux, and the web. Your data stays yours — no tracking, no ads, no data mining.
